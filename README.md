# Haniyeh Ahmadi Portfolio

A bilingual English/Persian portfolio for Haniyeh Ahmadi, built with Next.js, TypeScript, Tailwind CSS, GSAP, and React Bits-inspired components.

## Development

```bash
npm install
npm run dev
```

Production validation:

```bash
npm run lint
npm run build
```

## Environment

The site builds without environment variables. Contact-form delivery is enabled when these values are configured:

```text
RESEND_API_KEY=
CONTACT_TO_EMAIL=
CONTACT_FROM_EMAIL=
```

The production deployment is available at [haniyeh-ahmadi-portfolio.vercel.app](https://haniyeh-ahmadi-portfolio.vercel.app).
